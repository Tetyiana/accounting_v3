# Черга багів і задач

## Баги
1. Проводки при банківській операції → автоматично в дебітори/кредитори
2. ВВР/відпустка — діапазон дат «з...до» замість робочих днів
3. Накладна має форму акту → окремі друковані форми (акт послуг / видаткова накладна)
4. Журнал-ордер банку на смартфоні — не можна повернутися в меню
5. Ручне внесення операції — контрагент не записується в довідник
6. Журнал банк/каса — немає редагування запису (тільки видалення)
7. Ручні оплата і рахунок не перезакриваються — потрібна привязка всіх документів госп.операції до договору або рахунку

## Функції
- Реєстр документів (всі типи, фільтри, пошук)
- Supabase-міграція контекстів (schema виконана, ключі підключені)
- ПДВ: реєстр ПН/РК, розрахунок, XML J1201013, декларація
- Звітність ДПС: декларація ЄП, Єдина звітність XML
- ПРРО Checkbox: чеки, зміни, X/Z-звіти
- Кадровий облік: накази (прийом/переведення/звільнення/премія), друк
- PWA: перевірити маніфест, іконки, банер встановлення
- Мобільна версія: додаткове тестування
